# JSONPlaceholder Users

> A searchable SwiftUI user directory with profile details and async networking.

A sample app that retrieves users from JSONPlaceholder and separates response models, networking, services, view state, and presentation.

## Highlights

- Search users by name, username, email, or company.
- Open contact, address, and company details.
- Render loading, empty, and failure states with retry.
- Protocol-based networking and MVVM organisation.

## Open and run

1. Clone this repository and open `JSON Placeholder User/JSON Placeholder Users/JSON Placeholder Users.xcodeproj` in Xcode.
2. Select the app scheme and a simulator compatible with the deployment target in **Build Settings → iOS Deployment Target**. Use an Xcode version with SDK support for that target.
3. Build and run with **⌘R**. For a physical device, select your development team.

```bash
git clone https://github.com/sachinarkasali944/JSON-PlaceHolder-User-fetch.git
cd JSON-PlaceHolder-User-fetch
open "JSON Placeholder User/JSON Placeholder Users/JSON Placeholder Users.xcodeproj"
```

## Demo scope

JSONPlaceholder supplies demonstration records. This is a sample directory, not a production account system.
